# Security policy

This repository holds Renovate configuration only: no code that runs, and no secrets. A problem
here is most likely a rule that would let a malicious or compromised dependency update merge
itself, or that would hold back a security fix.

## Reporting a vulnerability

**Please do not open a public issue.** Report it privately through GitHub instead:
[Security ▸ Report a vulnerability](https://github.com/2Fivers/renovate-config/security/advisories/new).

We aim to acknowledge a report within 7 days.
